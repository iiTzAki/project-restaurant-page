# Project Restaurant Page
A multi-page restaurant website built using Webpack and modular JavaScript to dynamically render DOM content.

---

<h2 style="border-bottom: none;">🎯 Project Goals</h2>
- Set up a modern Webpack build to bundle modules and optimize assets.
- Implement dynamic page rendering through an organized, ES6 module architecture.
- Write Clean and Self-explanatory Code.
